# Daymark

个人使用的本地日程与项目工作台。包括月历、每日待办、任务笔记、项目看板和 `.ics` 日历导入。

当前版本：`0.6.1`。Daymark 已适合单人本地日常使用：日历、个人任务、项目子任务、随手记、项目状态栏、两套完成热力图、备份恢复和 Windows 桌面版均已打通。它仍是本地优先工具，不提供账号、云同步或多人协作。

## 使用评估

目前的可靠性重点是本地数据持久化和可恢复性：保存采用队列和原子替换，启动时会在主数据损坏时尝试读取备份，界面显示保存状态，数据与导入菜单支持 JSON 导出和恢复。正式使用前，建议先导出一份备份并放到项目目录之外。

尚未实现的能力包括重复任务、提醒通知、ICS 自动同步、撤销删除、批量操作和自动更新。这些功能会影响数据模型或系统权限，适合在真实使用一周后根据实际摩擦点再排优先级。

## Windows 桌面版

在 `release/` 中选择 `Daymark Setup *.exe` 安装版，或 `Daymark *.exe` 便携版。双击即可打开，无需安装 Node.js，也无需单独启动服务。两种版本都将记录保存在当前 Windows 用户的 `%APPDATA%\Daymark\data\` 中；同一台电脑的不同 Windows 账户各有自己的记录。便携版移动到别处时，记录不会随程序一起移动，迁移前请导出备份。

升级桌面版时，先在“数据与导入”导出 JSON 备份并关闭 Daymark。安装版运行较新版本的 `Daymark Setup`，安装到原来的位置；便携版下载新版 `.exe` 替换旧程序。两种方式都继续使用同一份用户数据，升级程序不会清空记录。当前没有自动更新功能。

0.2.0 起，日程与任务在月历日期格中分栏显示；当天日程有当前时间线。任务支持截止日期倒计时、预计完成时间、按预计完成日期分组，以及每项任务自己的笔记。旧任务无需迁移即可继续使用，新字段留空即可。0.2.1 起，月历中的鼠标滚轮只用于正常页面滚动；切换月份请使用箭头或月份选择器。

0.3.0 起，任务页显示过去一年的完成热力图。任务勾选完成时记录当天日期，取消完成会清除该日期；点击热力图中的日期可查看当天完成的任务。旧版已完成任务没有完成日期，不会被推测到热力图中。

0.3.1 起，月历中今天的日程栏也显示当前时间线，随时间更新；当天详情中的时间线继续保留。

0.4.0 起，Windows 桌面版的项目可以关联本地文件夹。在新建或编辑项目时选择文件夹，保存后可通过项目卡片上的“打开项目文件夹”和“用 VS Code 打开”按钮进入。关联只保存路径，不会上传或复制文件。Daymark 会查找常见的 VS Code / Insiders 安装位置及 PATH；找不到时可手动选择 Code.exe，并为当前电脑记住该选择。文件夹被移动或备份迁移到另一台电脑后，请在项目设置中重新关联。网页源码版不提供本地程序操作。

0.5.0 起，日历侧栏增加自动保存的“随手记”；我的任务与项目子任务分别管理，并提供各自独立的完成热力图。页面切换增加轻量过渡效果。

0.6.1 起，项目移除百分比进度和进度条；项目仍按“计划中、进行中、已完成”分栏管理，子任务继续在所属项目下单独管理。

从旧网页版迁移：先在旧版左下角“数据与导入”中导出 JSON 备份，再打开桌面版，在同一位置导入该备份。确认日历、任务和项目都已出现后，再决定是否保留旧版文件。独立笔记入口已移除；旧笔记仍保留在本地数据和 JSON 备份的 `notes` 字段中，但不会显示在界面上。公开安装包不包含 `data/` 中的个人记录。

需要自行构建时，在 Windows 上安装 Node.js 20.19+，运行 `npm.cmd install` 和 `npm.cmd run package:win`。安装版和便携版将生成在 `release/`。

## 从源码运行网页

需要 Node.js 20.19+。在项目目录运行：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

打开 http://127.0.0.1:5173/ 。服务只监听本机地址。

在 Windows 上，也可以双击项目根目录的 `Daymark.cmd`。它会在后台启动本地服务，并在 Edge 的独立窗口中打开 Daymark；如需桌面图标，右键这个文件，先选择“显示更多选项”（或按 Shift+F10），再选择“发送到 → 桌面快捷方式”。每次开机后双击该快捷方式即可。关闭窗口不会删除数据。
快捷方式仍依赖本机的 Node.js 和此项目目录；请勿只移动快捷方式对应的脚本而删除项目文件夹。

## 数据

从源码运行的网页版把记录写入 `data/planner.json`；桌面版写入 `%APPDATA%\Daymark\data\planner.json`。更新前的版本保存在同目录的 `planner.backup.json`。源码中的 `data/` 不会被 Git 跟踪，也不会进入桌面安装包。界面左下角的“数据与导入”可以导出或恢复 JSON 备份。建议定期把导出的备份另存到其他位置；本地存储本身不能代替备份。

Apple 日历或课表如果能导出为 `.ics`，可从“数据与导入”导入。第一版是一次性导入，不会自动与 iCloud 同步；重复导入同一份日历会跳过已有事件。其他课表格式需要后续针对具体样本支持。
